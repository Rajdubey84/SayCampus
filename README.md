# SayCampus – Empowering Students, Simplifying Complaints

**SayCampus** is a lightweight, local server-based student complaint portal designed to make reporting and managing grievances simple and efficient. It helps students voice concerns and allows administrators to respond instantly.

---

## Features
- 📝 **Anonymous Complaint Submission** – Students can submit complaints without revealing identity.
- 📊 **Admin Dashboard** – View, respond, and delete complaints with ease.
- 🔔 **Real-Time Notifications** – Get alerted whenever a new complaint is submitted.
- 👤 **User Profile** – Students can update their profile information.
- 🖱️ **Scrollable Complaint List** – Navigate through complaints smoothly without clutter.
- 💾 **Local Server Based** – Works fully offline using local storage, no external backend needed.

---

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Data Management:** Local Storage (with optional Firebase for future upgrades)

---

## How to Use
1. Clone or download the repository.
2. Open `index.html` in a browser for the student interface.
3. Open `admin.html` to access the admin dashboard.
4. All data is stored locally and updates automatically in the dashboard.
